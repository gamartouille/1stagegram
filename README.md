# PROJET

1stagegram est un projet personnel éphémère à destination des élèves de Géodata Paris (ex-ENSG Géomatique). En fin d'année, toutes les promotions se séparent pour partir en stage dans divers endroits, en France et autour du monde.
Pour garder le contact et donner des nouvelles régulièrement à ses camarades d'école, ce site, développé sur le modèle des anciens réseaux sociaux, permet de poster des photos avec une légende, et de réagir aux publications des autres utilisateurs.

# ASPECTS TECHNIQUES

Les bases de données étaient gérées avec Supabase, version premium pour la durée du projet.
Développé en Vue.js et en utilisant Vue Router, pour la compatibilité avec Supabase.

# VISUALISATION

Le projet était disponible à l'adresse 1stagegram.vercel.app.
A l'heure actuelle, il n'est plus possible d'accéder à davantage que la page d'accueil de 1stagegram, car la base de données a été mise en stand-by pour des raisons financières, mais également car les stages étaient terminés.
